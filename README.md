# melonpot-privacy

Public hosting for the MELONPOT privacy policy, required by Google Play Console
(App content → Privacy policy).

**Live URL:** https://achmad-r97.github.io/melonpot-privacy/

The game itself (source) lives in a separate private repository. This repo
contains only the published policy page.

## Updating

Edit `index.html`, bump the "Last updated" date, commit, push. GitHub Pages
redeploys automatically within a minute or two.

The canonical source text is `docs/play/PRIVACY_POLICY.md` in the game repo —
keep the two in sync when the policy changes (e.g. when ads or analytics are
added, which requires updating this page **before** that version ships).
